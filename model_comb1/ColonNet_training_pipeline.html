ColonNet Multi-Stage Training Pipeline

I. Hyperparameter Search (GWO)

Start: Initialize Script
Define `_gwo_objective` function (log10(LR), Dropout, Dense Scale)
Run GWO: Optimize `_gwo_objective` within defined bounds (1 iteration, 6 wolves simulated)
OUTPUT: Best Hyperparameters (`best_lr`, `best_dropout`, `best_scale`)

II. Stage 1: Bounding Box Branch Training

Load & Split Data: Only **Bleeding Images** (`with_neg=False`, `aug=True`)
Build `build_model` (Densenet) with GWO Hyperparameters
**Freeze Classification Layers** (`c_` layers)
Compile Model: Losses (BCE, MSE), Optimizer (AdamW with `best_lr`)
Train Bounding Box Branch for **10 Epochs** (`batch_size=64`)
MODEL SAVE: `CheckPoint1.h5`

III. Stage 2: Classification Branch Training

**Load Model** from `CheckPoint1.h5`
**Freeze Box Layers** (`b_` layers, `densenet121`) & **Unfreeze Classification Layers** (`c_` layers)
Load & Split Data: **All Images** (`aug=False`, `nums=2`)
Train Classification Branch for **10 Epochs** (`batch_size=64`)
MODEL SAVE: `classNbox.h5`

IV. Stage 3: Segmentation Model Training (ResUNet)

Load & Split Segmentation Data (`load_data_unet`); Reshape Masks to (224, 224, 1)
Build `Build_Unet_Model`
Compile Model: Loss (focal_tversky), Metric (tversky), Optimizer (adam)
Train Segmentation Model for **10 Epochs** with EarlyStopping, ModelCheckpoint, ReduceLROnPlateau
MODEL SAVE: `segmentation.hdf5`

V. Final Model Combination (ColonNet)

Load `upper` model (`classNbox.h5`) & `lower` model (`segmentation.hdf5`)
Set all layers in both loaded models to `trainable = False`
Create Final Model: Input layer feeds into both `upper` (→ l1) and `lower` (→ l2) models
END: Save Final Model as `ColonNet.h5` (Outputs: l1 and l2)
